Foundation

All 16 Leadership Principles

Every Amazon interview question maps to an LP. Prepare a STAR story for each — check them off as you go.

Behavioral

STAR Method Questions

Use "I" not "we". Quantify every result. Expect follow-up probes — interviewers will dig in on every point.

STAR: Situation → Task (your specific role) → Action (what YOU did) → Result (quantified outcome + learning)
Technical

System Design

You won't write code, but you'll lead the design conversation. Know trade-offs, failure modes, and AWS services at Amazon scale.

TPM Design Framework:
  • Clarify requirements — functional vs non-functional, scale, latency SLA
  • Back-of-envelope estimation — DAU × actions = QPS, storage needs
  • High-level architecture → deep dive on the bottleneck
  • Trade-offs: SQL vs NoSQL, sync vs async, consistency model
  • Failure modes + monitoring: what breaks, how you detect it, COE
Program Management

Delivery & Ambiguity

Own delivery from kickoff to launch across teams with no direct authority. Show you can navigate ambiguity at Amazon scale.

Working Backwards: Press Release → FAQ → Visuals → 6-pager narrative. Start with the customer outcome, work back to the engineering plan.
Product Sense

Customer Obsession in Practice

Always start with the customer. Use CIRCLES for design questions. Tie every answer back to Customer Obsession.

CIRCLES: Comprehend → Identify the customer → Report needs → Cut to priority → List solutions → Evaluate trade-offs → Summarize recommendation
